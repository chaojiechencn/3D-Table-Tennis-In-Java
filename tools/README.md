# Developer tools

These tools are optional and separate from the Java game and its build.

## IntelliJ MCP bridge

[`intellij-mcp-bridge/`](intellij-mcp-bridge/README.md) forwards an MCP client to the Claude Code
plugin in a local IntelliJ instance. It is a single-file Java program with no dependencies:
`java tools/intellij-mcp-bridge/Bridge.java --help`.
